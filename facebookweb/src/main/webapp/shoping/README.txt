FASHIONHUB RESPONSIVE SHOPPING WEBSITE
=========================================
Open index.html in a browser.

Pages:
- index.html       Home
- shop.html        Product listing, category filter, search, sorting
- product.html     Product detail
- cart.html        Working cart with quantity controls
- wishlist.html    Working wishlist
- login.html       Demo login using localStorage
- register.html    Demo registration
- about.html       About page
- contact.html     Working contact form demo

Technology:
HTML5, CSS3, JavaScript, Bootstrap 5.3, Bootstrap Icons.

Notes:
- Product data is in js/products.js.
- Cart, login and wishlist use browser localStorage.
- Product images use remote Unsplash URLs, so internet is required for images.
- This is a frontend demo; real authentication, payment and database APIs are not included.
